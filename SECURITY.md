# Security reporting / Sicherheitsmeldungen

Please report vulnerabilities privately to [plx@square-com.de](mailto:plx@square-com.de). Do not disclose a vulnerability, credentials or account data in a public issue. If this repository offers **Security → Report a vulnerability**, that private reporting channel is also available; check its availability in GitHub.

Schwachstellen bitte vertraulich an [plx@square-com.de](mailto:plx@square-com.de) melden. Schwachstellendetails, Zugangsdaten und Kontodaten nicht in öffentlichen Issues veröffentlichen. Falls das Repository **Security → Report a vulnerability** anbietet, kann auch dieser private Meldeweg verwendet werden; die Verfügbarkeit ist in GitHub zu prüfen.

For a private report, useful information includes affected PLX version, Docker/LoxBerry environment, impact and a minimal reproduction using synthetic data. Never send a real Porsche password, refresh token, VIN, location history, private key or unredacted backup. Use temporary test credentials only when strictly needed and agreed.

Für eine vertrauliche Meldung helfen PLX-Version, Docker-/LoxBerry-Umgebung, Auswirkung und ein minimales Beispiel mit Testdaten. Keine echten Porsche-Passwörter, Refresh-Tokens, Fahrzeugnummern, Standortverläufe, privaten Schlüssel oder unbereinigten Sicherungen schicken.

PLX is currently a preview. Fixes target the current preview branch; no long-term support or response-time commitment is offered. See [release status](RELEASE.md).
