## Definition of done

“Implemented”, “tested on the dedicated environment”, “independently reviewed”, “deployed” and “released” are separate states. A successful import, green unit suite, MQTT CONNECT or XML export does not establish a working end-user integration. The maintainer (@dubctrl) owns [#1](https://github.com/square-com-de/plx/issues/1); independent reviewer/test ownership and immutable acceptance references must be added there before closure. No Stable/`latest` promotion while that checklist remains open. This is a documented release gate, not a claim that GitHub technically enforces a promotion lock.

Do not attach credentials, VINs, locations, tokens or private backups to acceptance evidence. Use an isolated broker/prefix and disposable PLX data for tests. Do not change a running Taycan integration to validate PLX.
